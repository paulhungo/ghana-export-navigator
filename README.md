# Ghana Agricultural Export Navigator

A decision-engine website for Ghanaian agricultural exporters: answer 6 questions
(Product → Form → Quantity → Destination → Buyer → Transport) and receive a complete,
stage-by-stage export roadmap — registrations, regulators, certificates, packaging,
route, documents, costs, break-even price, readiness score and buyer resources.

## Run it locally
Double-click **START-Navigator.bat** (needs Python on the PC) and open
http://localhost:8087 — or just double-click `index.html` (works offline too).

## Publish (GitHub Pages)
1. Create an empty repository (e.g. `ghana-export-navigator`) on github.com
2. Then:
   ```
   git init
   git add -A
   git commit -m "Ghana Agricultural Export Navigator v1.0"
   git remote add origin https://github.com/<user>/ghana-export-navigator.git
   git push -u origin main
   ```
3. Settings → Pages → Deploy from branch: main / root. Live in ~1 minute.

## Structure
```
index.html          the app (wizard + roadmap + all sections)
admin.html          "Add product" tool — generates a JSON record for products.json
sw.js               service worker: offline-first (network-first with cache fallback)
version.json        build marker; the app auto-reloads when it changes (60s poll)
manifest.webmanifest
assets/             css, js (app.js engine, stages.js pathways+stage cards, tools.js tools)
data/               agencies.json, destinations.json, products.json, updates.json
                    (+ .json.js wrappers generated by _build/pack_data.py)
_build/             helper scripts (pack_data.py, make_icons.py) + regression test.html
```

## Updating data (the living database)
1. Edit `data/*.json` (or use admin.html for a new product)
2. Run `python _build/pack_data.py`
3. Bump `build` in version.json
4. Commit + push — every installed app updates within a minute

## Data honesty rules
- Every record carries `lastVerified` + `confidence`: 🟢 verified from the official
  source on that date · 🟡 from research — confirm with the agency · 🔴 warning.
- Only official sources (Tier 1 Ghana regulators, Tier 2 destination governments,
  Tier 3 international organisations) are authority for legal requirements.
- The site states clearly what it can and cannot do — verify with the regulator
  before any live shipment. Regulatory framework guide, not a legal opinion.

## Regression test
Start the server, then run headless Edge (or a browser) on
`_build/test.html` — it exercises the pineapple/UK, custom-product/EU,
coconut (tree-crop/TCDA)/UAE and frozen-fish/EU routes, the document
checklist, the profit calculator and the rejection solver. The page must
end with title `TESTDONE` and no `ERR:` banner.
